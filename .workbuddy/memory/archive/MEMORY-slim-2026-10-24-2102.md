## 数字与计数纪律
- **机读数字回原始文件重算**，计数带三元组：分子 / 分母口径 / 时点（HEAD 短哈希）。先分「字面 vs 展开」「声明数 vs 样本数」；百分比先验分母时点（一处旧通常多处旧）。
- **冻结配平 ≠ 可顺手改数**：曾把正确值「no-param 余 8」改成「勘误余 7」——配平砍叙述不砍数字。
- **OPEN-DECISIONS 计数**：取每行**最后单元格**，去 `*`/空白后截括注判 base；**禁按单元格数过滤**（78 条时点 21 行为 7 列、按 len==8 过滤漏 27%；**现总数 82 = 44 RESOLVED / 38 OPEN，比例须重算**）。
- **回执外部质疑三查**：① 引文方向 ② 同型先例是否已登记 ③ 计数口径（种类数 vs 提及次数）。只核结论不核引文 = 错因一起落盘。
- 改口径类修订传导核查：旧术语族 grep docs/ + scripts/ + 生成器源，逐处定性「活载体/历史记载」；收尾对已清文件重跑全量 grep（字符串字面量也是载体）。

## Security Center deny（R-6 已定论）
- **文件粒度、逐文件历史累积**（路径+工具史），非目录级、非 git 状态、非偶发 → **每个要动的文件先试一次**，失败即转用户系统终端，勿按目录推断。
- shell/python/grep 读被拦时 **Read/Edit/Write 可用**；已入库文件用 `git show HEAD:<path>` 绕过。**git 会静默失败**（status/diff 空但改动已落盘）→ 用 Read/Grep 实证。
- 机检脚本 fs 失败 → `git show HEAD:<path>` 兜底并打印 `[git-fallback]`；回退读的是 HEAD 版 → 收口顺序 = 先提交再跑门禁（gen_status_panel.py 同型兜底）。
- `docs/status-panel.html` 唯一刷新 `python -X utf8 scripts/gen_status_panel.py`，禁手改；取数前比对 mtime（**会静默过期**），生成器被拦则数字标不可信。
