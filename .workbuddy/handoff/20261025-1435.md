## 2. 必须传承的实测（全踩过，重踩各 10~20 分钟）

1. **`detail` 必须 `?? null`**：`JSON.stringify` 丢弃值 `undefined` 的键。去掉后 7003 响应变 `{code,message}`，**tsc 全绿**——「三出口形状一致」类型系统守不住。
2. **出站体不能 `satisfies ValidationErrorBody`**：`detail` 方向是 `{errors[]} → unknown` 单向可赋值。出站用 `ErrorBody`，管道细分用 `ValidationErrorBody['detail']` 定型，不用 `as`。
3. **`not-implemented.ts` 现零调用点**：保留，后续占位包会用；别因「没人用」删。
4. **真 HTTP 500 怎么造（不动源码）**：临时脚本放**仓库外** `/tmp/wo-boom-probe.cjs`，`Module({imports:[AppModule], controllers:[Boom]})` 起在 3101，控制器抛错，脚本内 `fetch` 取响应。两坑：① `@Controller('__boom')+@Get()` 实际路由是 `/api/v1/__boom` 而非 `/__boom/boom`（打错得 404 会误判「控制器没注册」）；② 仓库外脚本要 `require(`${process.cwd()}/node_modules/@nestjs/core`)`。
5. **别用 python 文本模式回写源文件**：会整文件变 CRLF，`.gitattributes` 锁 `eol=lf`。一律二进制模式 `replace(b'\r\n', b'\n')`。
6. **当前无任何端点挂 `ZodValidationPipe`**（首个在 P3-041）。400 校验出口取证只能走「真过滤器 + 假 `ArgumentsHost`」或 jest 用例，这是骨架期实况不是绕过。
