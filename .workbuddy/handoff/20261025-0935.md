## 2. 必须传承的实测（-06 及后续规则开发者）

1. **ESLint 9 flat config 无扩展名 glob 陷阱**：`files: ['**/*']` 按目录语义处理不匹配 `.ts`——RuleTester 顶层配置必须写 `files: ['**/*.{js,mjs,cjs,jsx,ts,tsx,mts,cts}']`，否则用例全落空「No matching configuration found」（报错不指根因）。
2. **规则内路径正则不能要求前导分隔符**：filename 可能是相对路径，须 `(^|\/)apps\//` 形态；`[\\/]apps[\\/]/` 会让 `apps/` 开头的路径静默不触发（规则写完必跑反向探针）。
3. **fixtures-run 的 CJS 单实例通道**：`createRequire`(shared) 解析 zod + `require(dist/cjs)`；ESM/CJS 混用 = 两个 zod 实例，`z.config` 只作用其一 → zhCN 断言假绿。运行器自己执行 `z.config(z.locales.zhCN())`（zh-locale.ts 的运行时等价物，删它即黑名单命中）。
4. **夹具引用契约逐字名**：`Error` schema 在夹具 JSON 里写 `"Error"`（别名重导出名），写 `ErrorSchema` 落空。
5. **反向验证四条已全部做过**（毒丸 / V-S2 咬合 / 判据 4 咬合 / lint 双面探针 + internal 豁免），探针均用后即删，细目见 ANCHORS v1.9 执行记录。
