# ADR-007: 不引入大而全组件库，自研外壳原子 + Radix 无样式行为原语

## Status

Accepted（2026-10-22，P3-001 工程化基线评审）
**注**：本条由 team-lead 代行裁定落盘（架构师裁决正文未送达，沿用 ADR-001 v1.8 先例，待架构师复核）。选型证据（体积、依赖树、peer、许可证）由前端专家实测并经 team-lead 复核。

## Background

DESIGN.md §4.1-§4.7 枚举的外壳原子约 10 个，§4 抬头强制「所有组件必须覆盖 9 态」；实际清单需 14 个（补 SPEC 有断言的头像堆叠与进度条）。Spec §8 规定 lucide-react 为全项目唯一图标来源；Spec §2 锁定 4 个页面，编辑器主体由 Univer Canvas 渲染，自研组件只覆盖外壳与表单。

候选：antd 5/6、Arco、Semi、Mantine、shadcn/ui、Radix Primitives。

## Decision

**自研 14 个外壳原子**（`packages/ui`），视觉 100% 遵循 design tokens；仅对「易写错且无视觉价值」的行为引入 **Radix 无样式原语 9 个**：dialog 1.3.1（焦点 trap / ARIA dialog）、dropdown-menu 2.2.1（键盘模型）、context-menu 2.4.1（视口边缘翻转）、tooltip 1.4.1（延迟与 ARIA 描述关联）、toast 1.3.1、avatar 1.3.1、tabs 1.2.1、progress 1.2.1、popover 1.3.1（定位基座）。

**否决清单与理由**
- antd 5.29.3 / 6.6.7：hard dependency `@ant-design/icons`（第二图标源，撞 P0-1 与 Spec §8 红线，且 Select/Table/Pagination 等内部图标**不通过 props 暴露替换入口**）+ `@ant-design/cssinjs` 运行时注入 + 46MB 落盘 + ConfigProvider token 与 design-tokens.css 双 token 源
- @douyinfe/semi-ui 2.104.0：36 依赖且拖入 `@tiptap/*` 富文本全族约 20 包 + semi-icons，58.2MB
- @arco-design/web-react 2.66.18：自带 color 与 icon 子包，16.42MB
- **@mantine/core 9.7.3：peer 要求 `react ^19.2.0`，与 Spec §4 锁定的 React 18.3.x 硬冲突**
- shadcn/ui CLI：需联网拉 `ui.shadcn.com` registry（信创离线不可行），且官方默认路径为 Tailwind v4 + React 19，与本项目 React 18.3 + Tailwind 3.4 不符；改为手工采纳其「源码入仓 + Radix」做法

**Radix 版本纪律**：各包主版本独立，**不存在「同代」概念**（dropdown-menu 与 context-menu 在 2.x 线，其余在 1.x 线）。CI 断言版本与 DESIGN.md §12.2 清单逐一相等。

## Consequences

**正面**
- 依赖面缩小一个数量级（Radix 9 包合计约 0.86MB vs antd 路线约 55MB 含图标）
- 无第二图标源、无第二套色板、不经第三方 CLI 拷贝源码进仓库，技术债完全受控
- token 变更时只需改自研一处，不存在与第三方库的样式特异性对抗

**负面**
- 14 个原子 × 9 态需一次性投入，估 7~9 人日（含 tokens 对齐与视觉走查）
- 无障碍行为正确性初期依赖 Radix 而非自有实现

**成本对比（数据口径，非感觉）**
自研 7~9 人日 vs 引入 antd 的一次性 token 桥接 3~5 人日。绝对值接近，但前者是**一次性**产出本项目所需资产，后者是**持续成本**（每次 token 变更需重验桥接、48 个直接依赖常驻镜像与许可证清单、图标双源长期靠 lint 拦截）。在依赖面相差一个数量级的前提下选一次性。

**缓解与回退**
- `no-restricted-imports` 永久拦截图标类第二来源；`wo/no-hardcoded-color` 保证组件只消费 token
- 任一原子自研工时 >3 人日（>2 倍），该原子允许改用 Radix / Headless UI 承担更多行为并登记 OPEN
- 若 Radix 某组件在 Chromium 100 下出现不可修的 focus-trap / pointer-events 缺陷，回退到「去掉 Radix，用原生 + `@floating-ui/dom`」（floating-ui 已随 Radix 间接引入，切换约 2 人日）
