# SB-01 前端立起来：`pnpm --filter @wo/web dev` 出一个能看的页面壳

> 所属切片：S0 立前端（第 1/2 块）｜ 预计 1 个会话 ｜ 2026-10-25

## 演示动作（收口时当场做）

1. `pnpm --filter @wo/web dev` 起来，浏览器打开 5173 端口。
2. 页面有顶栏（应用名 + 一个空状态提示）和一个占位的表格区域，不是白屏。
3. DevTools Console 无报错、无 React 警告。

## 规格（可直接使用，不需要再查被拦读的卡）

**技术栈**：React 18.3 + Vite 7 + TypeScript 5.9，包名沿用 `@wo/web`，ESM。

**文件形状**（新建）：

```
apps/web/
  index.html
  vite.config.ts
  src/main.tsx          ← createRoot + import './design/design-tokens.css'
  src/App.tsx           ← 页面壳：顶栏 + 表格占位容器
  src/design/design-tokens.css   ← 从 docs/design/design-tokens.css 原样复制
```

**设计令牌**：真源是 `docs/design/design-tokens.css`（230 个变量，命名 `--color-*` 等）。本块**原样复制**一份到 `apps/web/src/design/design-tokens.css`，在 `main.tsx` 最早期 import。业务代码里的颜色一律 `var(--color-xxx)`。

**必须改的一处既有配置**：`apps/web/tsconfig.json` 里 `"compilerOptions": { "types": [] }` 是为等 Vite 到位临时覆盖的（原注释写明）。Vite 一进来就要还原为 `"types": ["vite/client"]`，否则 `import.meta.env` 与 `.css` 导入全部 TS 报错。

**本块不引入 Tailwind、不引入组件库、不引入图标库。** 理由：体感验证不需要组件体系，手写少量 CSS 配上令牌更快，也少一轮构建配置。Tailwind（ADR-006）与 lucide-react 推迟到 UI 开始重复时（约 S5）再进。

## 允许硬编码 / 允许不做

- 页面中文文案直接写死在 JSX 里。
- 表格区域就是一个固定高度的 `div` 占位（写「表格区域」四个字即可），**不引 Univer**。
- 不做路由、不做状态管理、不做暗色模式、不做响应式断点。

## 不许碰（碰了是重写，不是补齐）

1. **`@wo/shared` 的导出面**：不改、不新增导出。且 `@wo/shared` 内部不得出现 React / Vite / Univer 的 import（`scripts/check-workspace-deps.mjs` 规则 H 会红）。
2. **`apps/server`**：一行不动。
3. **`apps/web/src/index.ts`**：保留原样（它证明 `@wo/shared` 在 ESM 侧可消费，是既有断言），不要删。
4. **颜色字面量**：除 `src/design/design-tokens.css` 外，任何源码不得出现 `#hex` / `rgb()` / `hsl()`——自定义规则 `wo/no-hardcoded-color` 会报错。
5. **emoji**：源码与文案都不得出现（`wo/no-emoji` 会报错）。
6. **依赖写法**：内部包一律 `workspace:*`；`apps/*` 之间不得互相依赖。
