## 2. 规格（已实测，可直接用）

**依赖**（全部 1.2.0，已确认存在）：

| 包 | 版本 | 说明 |
|---|---|---|
| `@univerjs/presets` | 1.2.0 | 组合入口，提供 `createUniver` |
| `@univerjs/preset-sheets-core` | 1.2.0 | 表格核心预设 |
| `rxjs` | >= 7 | **必须显式装**：它是 presets 的 peer 依赖，pnpm 不会自动补 |

**装法**（两个都是运行时依赖，不是 devDependency）：

```bash
corepack pnpm --filter @wo/web add -E @univerjs/presets@1.2.0 @univerjs/preset-sheets-core@1.2.0 rxjs
```

**API 签名以本文件为准，不要凭记忆写**：

```bash
# 装完后直接读这三个文件，是 AI 可读的（不属于被安全策略拦读的设计卡）
apps/web/node_modules/@univerjs/presets/lib/types/index.d.ts
apps/web/node_modules/@univerjs/preset-sheets-core/lib/types/index.d.ts
apps/web/node_modules/@univerjs/preset-sheets-core/README.md
```

预期形状（preset 路线）：`createUniver({ locale, locales, presets: [UniverSheetsCorePreset({ container: hostEl })] })` 拿到 `univer` 实例，再用 `univer.createUnit(...)` 建一个空工作簿；卸载用 `univer.dispose()`。**若与实际 types 不符，以 types 为准并在卡里订正。**

**样式**：`@univerjs/design` 的 `./lib/*` 可直接引，CSS 大概率在 `@univerjs/design/lib/index.css`（用 `corepack pnpm view @univerjs/design exports` 核对后引入）。样式不引会表现为表格挤成一团、列标丢失——这是最常见的假失败。

**容器**：`.sheet-slot` 现在是 `display:flex` 居中布局，Univer 需要**有明确高度的宿主**。改法：占位 div 换成 `<div className="sheet-host" ref={...} />`，CSS 给 `height: 100%; width: 100%;`，去掉居中与边框。

## 3. 已知风险（三条，都踩过或可预判）

1. **全局 `* { box-sizing: border-box }`** 在 `app.css` 里，会作用到 Univer 内部元素。若表格尺寸错乱，第一嫌疑就是它——届时把该规则收窄到壳选择器，或给 Univer 宿主重置。
2. **React StrictMode 会双次执行 effect**，Univer 实例若在 effect 里创建而未正确 dispose，会看到「两个表格叠在一起」。必须在 cleanup 里 `dispose()`。
3. **令牌与 Univer 的 CSS 变量可能同名**（我们的 `--color-*` 是通用名）。若 Univer 界面颜色异常，把壳的令牌作用域收窄到 `.app`，不要改令牌本身。
