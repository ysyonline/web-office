## 2. 规格（含三处实测订正）

**依赖**（全部 1.2.0，`saveExact` 锁定）：`@univerjs/presets@1.2.0`、`@univerjs/preset-sheets-core@1.2.0`、`rxjs@7.8.2`（peer 显式装）。均为运行时依赖。

**订正 ①：`workerURL` 不是必填，语义是「是否把公式挪到 worker」**

原卡写「workerURL 必填」不准确。实际 `preset-sheets-core/lib/es/index.js`：

```js
const useWorker = !!workerSrc;              // 不传即 false
useWorker ? [UniverRPCMainThreadPlugin, { workerURL: workerSrc }] : null,
[UniverFormulaEnginePlugin, { notExecuteFormula: useWorker }],
```

即**不传 → 公式在主线程执行（`notExecuteFormula:false`），照常计算**；传了却忘了在 worker 侧起
`UniverSheetsCoreWorkerPreset` 才会静默不算。本包取「不传」，单表演示量级不需 worker。

**订正 ②：CSS 只引一条聚合产物**

引 `@univerjs/preset-sheets-core/lib/index.css`（201KB，自包含，design/ui/sheets-ui 样式已合入）。
不要再单独引 `@univerjs/design/lib/index.css`——同一批类会重复定义、后者覆盖前者。
顺序：`design-tokens.css` → Univer 聚合 CSS → `app.css`（壳样式最后，可覆盖引擎 reset）。

**订正 ③：`container` 必须传 HTMLElement，不能传 id 字符串**

`@univerjs/ui` 的 `bootstrap` 里字符串分支走 `document.getElementById`，**查不到时会 `createElement`
出一个游离节点且不 append**，表现为「实例建成功、界面不出现」。传元素绕开这条静默失败路径。

## 3. 三条已知风险的实测结论（全部与预判不同，别照抄旧假设）

1. **全局 `* { box-sizing: border-box }` —— 未触发**。截图列宽/行高正常，保留原规则。
   退路仍记：若后续出现尺寸偏差，改 `.app` 作用域重置，再给 `.sheet-host` 内还原。
2. **StrictMode 双次 effect —— 真实形态比预判严重得多**。不是「两个表格叠在一起」，而是
   **表格完全不出栅格（canvas=0）+ 控制台报 `Attempted to synchronously unmount a root while
   React was already rendering`**。根因：Univer 的 `dispose()` 内部同步 `ReactDOM.root.unmount()`，
   而 StrictMode 的 cleanup 仍在本轮提交批内。
   试过「独立子容器 + `setTimeout(dispose, 0)`」：栅格出来了，但转为 `NotFoundError: removeChild`
   未捕获异常——**只是把竞态换了位置**。
   最终方案：**以宿主节点为键的 WeakMap 复用实例，effect 不做卸载**（与 Univer 官方 React 示例
   一致）。落地在 `src/sheet/SheetHost.tsx`，理由写在文件头。
3. **令牌变量同名冲突 —— 不成立**。Univer 变量统一 `--univer-tw-*` / `--univer-gray-*` /
   `--univer-primary-*` 前缀，与自有 `--color-*` 零重叠。无需收窄作用域。

## 7. 欠账（收口时填）

1. **主包 6.7MB（gzip 1.8MB）未做代码分割**：Univer 全量进主 chunk，另有大量语言包分块
   （cy/grc/hu…）被自动切出。本地首屏体感尚可，但 V5「发链接给别人」前必须按需加载。
   归属：V5.1 / 性能线。
2. **实例没有确定的销毁时机**：WeakMap 复用避开了 StrictMode 竞态，但也意味着路由化/多文档切换
   时不会及时回收。归属：V2（一文档一实例）。
3. **只验证到「空表 + 输入文本」**，未验证公式计算、合并单元格、数字格式。归属：V1.2.2 / V1.3。
4. **仅在 Edge 122 headless 取证**，未在主力浏览器与真实分辨率下手动确认。
5. **`protobufjs` 构建脚本裁决为 `false`**：读源码确认其 postinstall 只打印版本方案警告、
   不编译不联网，按 ADR-005 最小构建面原则关闭。若升级到真正做代码生成的版本须改判。
