## 2. 规格

**数据形态**（`apps/web/src/sheet/demo-workbook.ts`，与挂载逻辑分离，V1.3 三格式继续在此长）：

```ts
{
  id, name, appVersion: '1.2.0', locale: LocaleType.ZH_CN, styles: {},
  sheetOrder: ['wo-demo-sheet'],
  sheets: {
    'wo-demo-sheet': {
      id, name: 'Sheet1', rowCount: 24, columnCount: 15,
      cellData: {
        0: { 0: { v: 1, t: CellValueType.NUMBER } },   // A1
        1: { 0: { v: 2, t: CellValueType.NUMBER } },   // A2
        2: { 0: { f: '=SUM(A1:A2)' } },                // A3：只有 f
      },
    },
  },
}
```

三条硬约束：

1. **`sheetOrder` 与 `sheets` 键逐字一致**，否则 `Workbook` 构造丢表。
2. **公式字段是 `f` 且带 `=` 前缀**（不是 `formula`）。
3. **A3 不给 `v`、不给 `t`**：值必须由引擎产生；`t` 预先写 `NUMBER` 等于替引擎下结论。

**取值口径**：`SheetHandle.getValueByA1(a1)` → `fWorkbook.getActiveSheet().getRange(a1).getValue()`。
只走 facade，不读 `getCellMatrix()`——后者读的是缓存层，在「初算不冲缓存」前提下等于自证。

**dev-only 句柄**：`mountSheet` 在 `import.meta.env.DEV` 分支下挂 `window.__woSheet`（返回同一 `SheetHandle`），
供探针经 CDP 读断言；生产构建此分支被静态剔除（构建产物中无 `__woSheet`）。

## 3. 判据

### 3.1 有效断言

| 格 | 期望 | 实测 | 说明 |
|---|---|---|---|
| A1 | 1（number） | 1（number） | 常量，对照组 |
| A2 | 2（number） | 2（number） | 常量，对照组 |
| A3 | 3（number） | **3（number）** | 载入时**无缓存值**，故该值只能由公式引擎算出 |

探针按 200ms 轮询、上限 6s，记录「第几次轮询首次非 null」。本次三格均第 1 次轮询即非 null
（页面加载后 canvas 已就绪 + 1.5s 稳定窗）。**轮询而非固定 sleep** 的理由：首次计算的精确时机在
preset 装配下无法预设，固定 sleep 分不清「算完了」与「还没算但读到了别的值」。

### 3.2 反向对照（本包最重要的一条实测，不止是引用 spike）

把 A3 临时改成 `{ v: 99, t: NUMBER, f: '=SUM(A1:A2)' }` 后重跑探针：

```
[断言] BAD A3 期望 3（number）｜实得 99（number）｜首次非 null 于第 1 次轮询
```

**引擎在载入时没有纠正错误缓存**——这同时证明两件事：

1. `spike` §1 B1/B2 的「初算不冲缓存值」在 **preset 装配下同样成立**（spike 是自建插件链，此前只是推断同构）；
2. 若按直觉写 `v: 3, f: '=SUM(A1:A2)'`，「A3 显示 3」**必然是假绿**——它只证明缓存被显示，不证明引擎算过。

对照验证后已回退为「只有 `f`」，`getValue` 复绿。这条对照是「判据可信」的证据链，不是可选优化。

## 7. 欠账（收口时填）

1. **首次计算的精确时机未量化**：本次三格均在第一次轮询即非 null，说明在「canvas 就绪 + 1.5s」
   之后早已算完；但**公式入队到出值**的真实耗时没测。若后续出现「大表载入后首帧空白」，
   归因方向是计算时机而不是数据形态。归属：V1.3.2 或性能线。
2. **断言依赖 dev 句柄 `window.__woSheet`**：生产构建无此入口，故生产态只能靠截图。
   V5「发链接给别人」前若需要生产态自动化验收，须另设受控入口（或纯 CDP + 无障碍树），届时再裁。
3. **单表单实例**：`getValueByA1` 走 `getActiveSheet()`，多表时语义是「当前活动表」。归属：V2。
4. **未验证编辑触发重算**（改 A1 → A3 变）——这正是 V1.2.3，不在本包范围。
