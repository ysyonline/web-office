## 2. 规格：三格式全部写进 `IWorksheetData`，不挂载后调 API

V1.3.1 要验的是「载入后三种格式共存且互不破坏」。写进数据走快照路径，与 V4 导入真实 xlsx
**同构**（同样从数据进、由引擎还原格式）；挂载后逐一调 `merge()` / `setFontWeight()` 验的是另一条链路。
取前者。

| 格式 | 落点 | 关键字段 |
|---|---|---|
| 合并 | `sheets[id].mergeData` | `IRange[]`，行列从 0 起、闭区间（A5:B6 → `{4,0,5,1}`） |
| 加粗 + 底色 | `styles['style-emphasis']` | `{ bl: BooleanNumber.TRUE, bg: { rgb } }` |
| 货币 | `styles['style-currency']` | `{ n: { pattern: '¥#,##0.00' } }` |
| 引用方式 | `cellData[r][c].s` | 样式 **id 字符串**，指向顶层 `styles` 表 |

`styles` 从 `{}` 变为非空，顺带验证了 V1.2.2 卡里列为「未核实」的那条：**顶层 `styles` 表 → 单元格 `s` 引用**这条快照路径可用。

### 2.1 底色为什么必须从 CSS 变量取（不是「随便写个 #fffbeb」）

`wo/no-hardcoded-color` 禁止 TS 里出现 `#hex` / `rgb()` 字面量，而 Univer 单元格样式要的是**具体色值字符串**。
三条路只有第三条站得住：

1. 用具名色 `'yellow'` 绕过规则——字母上放过，精神上正是规则要防的事，**不取**；
2. TS 里复制一份色板——两处真源必然漂移，**不取**；
3. **运行时读 `design-tokens.css` 的 CSS 变量**（`design/read-token.ts`）——唯一真源仍是令牌文件，**取这条**。

令牌缺失时 `readTokenColor` **抛错而不回退**：静默回退会让「底色没生效」看起来像「本来就没这需求」。
探针反向验证了这条链路——它把页面里读到的令牌值与单元格 `bg.rgb` 比对，两处不一致即红。

## 3. 判据

### 3.1 四条主断言 + 一条兜底

| # | 断言 | 为什么不能更宽 |
|---|---|---|
| 1 | 合并区**恰为** A5:B6（与 A18:B19），数量与坐标都对 | 「有一个合并区」这种断言，在合并错位时照样绿 |
| 2 | 合并区非左上格不存值（B6 = null） | 四格都写字也会「看起来是合并的」，那是完全不同的语义 |
| 3 | 货币格 `getRawValue` = 1234.5 且显示 `¥1,234.50` | 只断言显示，无法排除「值被改成文本」；只断言值，无法证明格式生效 |
| 4 | 加粗格 `bl = 1` 且 `bg.rgb` **等于页面里的令牌值** | 断言等于字面量 `#fffbeb` 就绕回了硬编码 |
| 5 | 兜底：A3 仍为 3 | 上格式之后公式是否被破坏，是本包真正的风险点 |

### 3.2 实测发现：`getValue` 与 `getRawValue` 在格式化格上不同

```
getValue('C1')    → '¥1,234.50'   （格式化文本，string）
getRawValue('C1') → 1234.5        （数值）
getDisplayValue('C1') → '¥1,234.50'
```

这条分歧决定了本包的断言口径：

- 若断言 `getValue === 1234.5` → **永远红**；
- 若断言 `getValue === '¥1,234.50'` → 把「读数口径」写死成一个将来可能变的实现细节；
- 故断言 **`getRawValue` 是数值 + `getDisplayValue` 是货币文本**，两者各证一半，且不锁死实现。

**下游影响**：任何「读出来再算」的代码（导出、统计、协同 diff）在格式化格上都不能用 `getValue`，
否则拿到的是字符串。已登记为 §7 欠账 1，V4 导入导出开工前必须先处理这条口径。

## 7. 欠账（收口时填）

1. **`getValue` / `getRawValue` 的分歧未扩散排查**：本包只在货币格上确认了差异，未系统验证
   「哪些格式会触发这条分歧」（百分比、日期、千分位各自如何）。V4 导入导出、V6 前必须查清。
2. **合并区只验了「只读」形态**：未验在合并区上写值、拆并、以及合并区参与编辑时的行为。
   归属：V4（真实表进来常带合并）。
3. **货币符号写死为 `¥`**：pattern `'¥#,##0.00'` 是硬编码文案，多币种/多语言场景需要改成按 locale 选。
   归属：V5（给别人用）或国际化线。
4. **数字格式只验了显示，未验编辑态**：双击进入编辑时显示的是原始值还是格式化文本，未取证。

**组合运行的顺序约束**（实测踩过）：`--set` 会改动页面状态（A1 1→5、A3 随之 3→7），必须排在
`--formats` / `--boundaries` **之后**——后两组断言描述的是「载入态」。探针内部已按此顺序固定，
调整顺序会让格式段的「公式未被格式破坏 A3=3」变红，而那不是 bug，是 A3 已被重算成 7。
全量一条命令：

```bash
node scripts/probe-web.mjs --assert=A1=1,A2=2,A3=3 --set=A1=5 --after=A1=5,A3=7 --formats --boundaries
```
