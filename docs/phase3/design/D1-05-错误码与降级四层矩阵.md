## ② 时序 / 状态机

**错误出口判定时序（服务端，每个异常按序短路）**

```
异常/关闭事件
  → ① 是否 WS 生命周期事件？
       是 → 按 close-codes 表返回（4401/4403/4409/4410/4411/4412），
            4411 前置发 [CONTROL] session-invalidated；结束
  → ② 是否 body-parser / multipart 解析失败？→ 400 + 7003（产生点在 pipe 之前，全局过滤器承接）
  → ③ 是否 ZodValidationPipe 校验失败？→ 按 D1-13 分流 7001/7002/7004 → 400；结束
  → ④ 是否业务规则拒绝？（按 registry 逐码 → 对应 HTTP，见 ① 栏全表）；结束
  → ⑤ 是否 License 判定失败？→ 按 D1-10 判定链：HTTP 侧 402（写端点）或 403（降级后写操作）、
       WS 侧 4409、Command 层守卫三出口**同时生效**（见下方一致性约束）；结束
  → ⑥ 兜底 → 500 + 9001（detail.requestId）；依赖不可用 → 503 + 9002
```

**同语义多出口一致性（本卡核心约束）**

License 无效/缺失/过期必须**三个出口语义等价**，任一出口单独实现即视为不一致（AC-09 逐条断言；缺失态归属本约束，条 K）：

**分域注（v1.2 修订，S1 裁决）**：4409 属 **License 域**（无效/缺失/过期），不属席位域。席位满（License 有效但席位用尽）在 WS 侧**无 close 码**——新 edit 首连降级 view、ROLE_UPGRADE 满席回 role-upgrade-reject 帧，连接均不中断（D1-08 v1.1 裁定，依据 Spec §10；openapi `server-responsibilities` 超席句漂移已登记 OPEN，随解冻窗口修）。**已裁决（v1.3，2026-10-23 架构师）**：AC-09 措辞已在 Spec §9 按本分域统一（超席项 WS 侧 = 角色降级 view、连接存活、无 close 码），QA 断言以修订后 AC-09 为准（P3-135-08 经 D1-10 V-4EXIT 分解执行），本分域结论升格为权威。

| 出口 | 触发位置 | 行为 |
|---|---|---|
| HTTP 402 / 403 | 写端点（新写操作 / 降级后的写操作） | code 5001，detail `{ reason }` |
| WS 4409 | License 无效/缺失/过期时的新编辑首连 / 导入互斥拒新 UPDATE（**ROLE_UPGRADE 判席不属本码**：满席回 role-upgrade-reject 帧，无 close） | 连接降级 view 或拒绝，不中断既有编辑 |
| Command 守卫 | Univer `beforeCommandExecuted`（写类 Command） | 拦截执行 + 只读 banner（pages.md §3.10 三态文案） |

**失败分支与回滚点**：① 实现中发现 registry 缺码/码语义不足 → 开 OPEN-DECISIONS 走解冻，**不得复用邻近码或自造码**；② HTTP status 与 code 映射冲突（如某端点把 5001 挂在 403 之外的状态）→ 以 registry 语义 + 本卡全表为准改代码；③ WS close 与 HTTP 侧对同一事件给出矛盾结论（如 HTTP 已 402 而 WS 仍可编辑）→ 按 ② 的三出口等价约束判不一致，修复到等价。

> **兜底规则（v1.1 补，复评轮挑刺；v1.4 扩为九码两类，P0-4/P1-9b）**：registry 中**当前无任何操作挂载**的码共 **9 个**（机读：29 操作 responses 零 example 引用），按产生方式分两类处理，本表不再只列原四码：
>
> | 类别 | 码 | 处置 |
> |---|---|---|
> | **纯预留码**（无产生路径） | 2002（文件名冲突或非法）/ 3003（解析失败）/ 4001 / 4002（WS close 对应码） | 不设呈现档位，挂载时随契约解冻补档 |
> | **运行时产生码**（有产生路径、仅契约未显式挂载） | 7002（查询参数越界）/ 7003（JSON·multipart 非法）/ 7004（路径参数格式非法）/ 9001（兜底 500）/ 9002（依赖不可用 503） | **有呈现档位（本表 A/B/C/D 档已全部覆盖）**，产生路径分别见 D1-13 ② 校验链与 D1-11 ② readiness；**不进 V-2 抽查面**，由 D1-13 E-CV 行为断言与 D1-11 V-READY 兜底 |
>
> 除此之外**凡已挂载码必须在本表有归属，漏项即本表缺陷**（1005 即补此例：D1-09 ③ 已映射而本表原缺项）。

WS close → 前端呈现（协同侧）：4401/4411 → 清会话回登录页；4403 → toast「无编辑权限」；4409 → **按上下文分流**（v1.1 立）：License 无效/缺失/过期 → 只读 banner（同 5001 态）；**满席/超席无 close 码**（新连降级 view / ROLE_UPGRADE reject 帧，按角色提示，不走 close 呈现——D1-08 v1.1 与 Spec §10 口径）；**导入互斥窗口拒 UPDATE**（判别依据＝该连接已收 [CONTROL] doc-rebuild 帧）→ **不走只读 banner**，按保存四态「离线待同步」缓冲、重建完成后重放（D1-01 ② 失败分支 ③ 落行）——4409 不得一律映射只读；4410 → toast「连接数已达上限」；4412 → toast「服务繁忙」+ 重试引导。
