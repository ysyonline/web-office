## ② 时序 / 状态机

**错误出口判定时序（服务端，每个异常按序短路）**

```
异常/关闭事件
  → ① 是否 WS 生命周期事件？
       是 → 按 close-codes 表返回（4401/4403/4409/4410/4411/4412），
            4411 前置发 [CONTROL] session-invalidated；结束
  → ② 是否 body-parser / multipart 解析失败？→ 400 + 7003（产生点在 pipe 之前，全局过滤器承接）
  → ③ 是否 ZodValidationPipe 校验失败？→ 按 D1-13 分流 7001/7002/7004 → 400；结束
  → ④ 是否业务规则拒绝？（按 registry 逐码 → 对应 HTTP，见 ① 栏全表）；结束
  → ⑤ 是否 License 判定失败？→ 按 D1-10 判定链：HTTP 侧 402（写端点）或 403（降级后写操作）、
       WS 侧 4409、Command 层守卫三出口**同时生效**（见下方一致性约束）；结束
  → ⑥ 兜底 → 500 + 9001（detail.requestId）；依赖不可用 → 503 + 9002
```

**同语义多出口一致性（本卡核心约束）**

License 超席/过期必须**三个出口语义等价**，任一出口单独实现即视为不一致（AC-09 三层防线逐条断言）：

| 出口 | 触发位置 | 行为 |
|---|---|---|
| HTTP 402 / 403 | 写端点（新写操作 / 降级后的写操作） | code 5001，detail `{ reason }` |
| WS 4409 | 新编辑连接 / ROLE_UPGRADE 判席 / 导入互斥拒新 UPDATE | 连接降级 view 或拒绝，不中断既有编辑 |
| Command 守卫 | Univer `beforeCommandExecuted`（写类 Command） | 拦截执行 + 只读 banner（pages.md §3.10 三态文案） |

**失败分支与回滚点**：① 实现中发现 registry 缺码/码语义不足 → 开 OPEN-DECISIONS 走解冻，**不得复用邻近码或自造码**；② HTTP status 与 code 映射冲突（如某端点把 5001 挂在 403 之外的状态）→ 以 registry 语义 + 本卡全表为准改代码；③ WS close 与 HTTP 侧对同一事件给出矛盾结论（如 HTTP 已 402 而 WS 仍可编辑）→ 按 ② 的三出口等价约束判不一致，修复到等价。

## ③ 错误码映射

前端呈现档位三档（判定条件写死，按序短路）：

| 档位 | 判定条件 | 表现 | 出处 |
|---|---|---|---|
| **A 字段级** | code=7001/6003 且 `field !== '(root)'` | `detail.errors[]` 按 field 映射到表单字段下方 | P3-001 §4 |
| **B Toast（可继续）** | A 不命中且操作可重试：7001 `(root)`、7003、409 族（1006/1009/2004/2005）、413 族（2003/3001）、422 族（1008/3002/5002/6003 非 errors 形态）、6001/6002 | Toast 错误类 5000ms，页面不跳转 | P3-001 §4 + pages.md Toast 用法 |
| **C 页内态（阻断单操作）** | 7002（列表页「筛选条件无效」+ 重置筛选）、7004（跳 404）、404 族（2001 文件不存在 / 1007 用户不存在）、列表加载失败（错误码 13px `--color-meta` 展示 + 重试） | 页内状态替换，不弹全局 | P3-001 §4 + pages.md §2/§3 Error 态 |
| **D 全屏阻断/会话级** | 401 族（1001/1002/1003/1004 → 登录页，1001 保留输入不清密码框）、1002 锁定（423，倒计时 `role="timer"`）、**1005（403 无权限/disabled → 登出引导——v1.1 补：D1-09 ③ 早已映射 D 档，本表原枚举缺项）**、9001（显示 detail.requestId 等宽独立行）、9002、License 只读态（5001 → 只读 banner 常驻，三态文案按 pages.md §3.10） | 登录跳转 / 全局 banner / 错误页 | P3-001 §4 + pages.md §1.4/§3.10 |

> 与 DESIGN-LAYER §3.2 条 4「前端三档」的对应：A+B = toast 档（可继续），C = 页内态（阻断单操作），D = 全屏阻断（会话失效/只读）。本卡把「字段级」从 toast 中拆出单列，因 7001 的 field 映射是 P3-001 §4 已定稿的独立解析路径。

> **兜底规则（v1.1 补，复评轮挑刺）**：registry 中 2002（文件名冲突或非法）/ 3003（解析失败）/ 4001 / 4002（WS close 对应码）**当前无任何操作挂载**（机读：29 操作 responses 零 example 引用）——预留码不设呈现档位，挂载时随契约解冻补档；除此之外**凡已挂载码必须在本表有归属，漏项即本表缺陷**（1005 即本轮补此例——D1-09 ③ 映射了 D 档而本表枚举缺项，实现者按表实现则 1005 落进无档位盲区）。

WS close → 前端呈现（协同侧）：4401/4411 → 清会话回登录页；4403 → toast「无编辑权限」；4409 → **按上下文分流**（本卡 v1.1 补，复评轮挑刺）：License 无效/缺失/过期 → 只读 banner（同 5001 态）；**满席/超席无 close 码**（新连降级 view / ROLE_UPGRADE reject 帧，按角色提示，不走 close 呈现——D1-08 v1.1 与 Spec §10 口径）；**导入互斥窗口拒 UPDATE**（判别依据＝该连接已收 [CONTROL] doc-rebuild 帧）→ **不走只读 banner**，按保存四态「离线待同步」缓冲、重建完成后重放（D1-01 ② 失败分支 ③ 落行）——4409 不得一律映射只读；4410 → toast「连接数已达上限」；4412 → toast「服务繁忙」+ 重试引导。
