## ② 时序 / 状态机

**启动断言链（顺序固定，任一步失败即退出码 1 并指名失败步）**

```
main.ts 引导
  → ① loadConfig()：zod 解析环境变量
       ├─ 必填缺失 → 「[config] 缺少必填键 WO_JWT_SECRET」→ exit 1
       └─ 可选键非法 → 「[config] WO_PORT=abc 非 port」→ exit 1
  → ② 三级国密断言（license/design §2.5，探针 scripts/gm-crypto-probe.mjs 已固化）：
       G1 getHashes 含 'sm3' → G2 getCurves 含 'SM2' → G3 SM2 自签自验真跑
       任一失败 → 「[gm] G2 曲线 SM2 不存在」→ exit 1
       （离线包形态不提供跳过开关——跳过开关即安全后门，见 ④ V-SKIP）
  → ③ DataSource.initialize()（synchronize:false）
       失败 → 「[db] WO_DB_URL 不可达」→ exit 1（不重试——启动期重试掩盖配置错误）
  → ④ License 公钥解析（WO_LICENSE_PUBLIC_KEY → KeyObject）
       失败 → 「[license] 公钥 PEM 解析失败」→ exit 1
  → ⑤ Nest bootstrap → health 端点就绪 → 日志「startup ok」
```

**健康检查分级（liveness 与 readiness 是两个语义，不可合并）**

| 端点 | 语义 | 检查项 | 失败行为 |
|---|---|---|---|
| `GET /api/v1/health` | liveness（进程活） | 无（进程能应答即活） | 无应答 → 编排器重启（正确行为） |
| `GET /api/v1/health/ready`（本卡新定） | readiness（依赖可用） | ① DB `SELECT 1` ② License 公钥已装载 ③（容器形态）verdaccio 离线源可达性不查——那是构建期依赖非运行期 | **503 + 9002**；**编排器不得据 readiness 重启进程**（依赖故障重启只会放大故障），只应停止接入流量 |

**失败分支与回滚点**：① 三级断言只做启动期一次性检查，不做运行期轮询（运行期 sm3 不会消失）；② readiness 检查带 3s 超时，依赖抖动时 503 但进程存活——与 9002「依赖不可用」语义一致（D1-05 ② 栏第⑥步）；③ 配置热更新**不支持**——改配置 = 重启进程（SIGTERM 优雅关闭 → 30s drain → 重启，Spec §10 序列）；④ 容器形态默认值来源 = 镜像内 ENV 基线 + compose `environment:` 覆盖；裸机形态 = systemd `EnvironmentFile=/etc/web-office.env`（0600 权限）。**两形态键名完全一致**，差异只在注入载体。

## ③ 错误码映射

| 边界 | code | HTTP | 前端呈现 | 出处 |
|---|---|---|---|---|
| readiness 探针依赖不可用 | **9002** | 503（health/ready） | D 档全屏阻断（运维面，非用户面） | registry + D1-05 ② 第⑥步 |
| 启动失败（配置/断言/DB/公钥） | —（进程退出码 1） | 无 HTTP（未监听） | —（日志指名失败步） | 本卡新定 |
| TZ/时区错误写入 | 防线 = schema.md 约定 + Code Review | — | —（结构性预防，无码可映射） | schema.md §1 |

> 本卡不新增业务错误码。启动期失败走进程退出码不走 HTTP（进程未监听时无响应方可被编排器正确判定崩溃）；运行期与配置相关的唯一新出口是 readiness 503+9002，已在 registry。

## ④ 验收断言补充

| # | 断言 | 落点包 |
|---|---|---|
| V-KEY | 三分类全表机器可核：`loadConfig` 的 zod schema 与本卡 ① 栏逐键一致；新增键未入卡即 FAIL（卡是配置键唯一注册表） | P3-012 |
| V-FAIL | 每个必填键逐一置空启动 → exit 1 且日志含键名；`WO_PORT=abc` / `WO_PBKDF2_ROUNDS=9999` / production 下改 `WO_ACCESS_TTL_MIN` → 均 exit 1（失败语义逐键断言） | P3-012 / P3-016 |
| V-SKIP | 全库 grep `SKIP_GM|WO_GM_SKIP|skipAssert` 零命中——离线/测试/任何形态**无断言跳过开关**（安全后门禁令） | P3-016 |
| V-READY | `health/ready`：DB 停 → 503+9002 且进程存活（不退出）；DB 恢复 → 200；compose/编排配置中 readiness 失败**不得映射 restart 策略**（断言编排文件无此映射） | P3-016 / P3-019 |
| V-DEF | 默认值全表快照测试：空环境变量集启动（仅给 3 个必填键）→ 全部可选键取本卡默认值，与 Spec/ADR 出处数值逐一相等（15/7、5/15、32MB、10MB、80%、100、1s/50、30s、5s、60s、7 天、100000 轮、1792MB） | P3-012 |
| V-GM | 三级断言失败注入（stub getCurves 去掉 SM2）→ exit 1 且日志指名 G2（断言链非恒真） | P3-016 |
