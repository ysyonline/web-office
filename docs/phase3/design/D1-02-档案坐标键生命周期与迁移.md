## ① 接口 / 数据结构

| 项 | 定义 | 出处 |
|---|---|---|
| 键形态 | `formula-archive:{sheetId}:{row}:{col}`，row/col 0 起；**sheetId 裁决：用 Univer 内部 sheet id**（快照/引擎/mutation 参数同源——insert-row 等 MUTATION 参数携带的就是 sheetId），**不用 sheet 名**（重命名不改 id 即零迁移；名字可重名、id 唯一）。副作用：档案不随重命名变，导出按 id→名映射还原（快照内自带） | plan 规则 2 + **本卡新定**（id vs 名裁决 + 重命名零迁移） |
| 值结构 | `{ f: string, v: import 时值, source: … }`——source 值空间 = `import`（普通冻结/差分降级，plan 规则 2）/ `import-static`（W 内 volatile 静态化，plan 规则 1）/ `diff-mismatch` 等（**本卡新定**：差分降级格的档案来源值）；**v 必填**（值校验比对基准，plan v1.4 P0 规则 6），唯一例外 = 无缓存值公式格 `v=undefined`（D1-03 ② 失败分支 ③，过闸规则见 ② 值校验行）——**source 与 D1-03 降级原因码是两个字段**：前者随档案条目持久化，后者只进 import_tasks，两者值空间有交集但互不从属 | plan 规则 1/2/6/12 + D1-03 ① |
| 载体 | snapshot `resources` 侧车（IResources 数组，resource name `SHEET_FORMULA_ARCHIVE_PLUGIN`，插件级官方载体）；运行态 = Y.Map（协同同步）；物化 = resources 从权威 Y.Map 整表重写（A6，与 D1-01 一致） | plan 规则 2/4 + ADR-001 v1.5 规则 3 |
| 编辑失效规则 | 用户编辑命中档案格（SetRangeValuesCommand）→ 拦截器**删除档案条目**（新内容成唯一事实）；白名单内新公式照常进数据层；失效经 Y.Map 同步对端 | whitelist §3 规则 4 + plan 规则 3 |
| 结构 op 迁移公式（五类迁移 + 排序兜底） | 设档案件 (s,r,c)，op 作用于 s：**insert-row(n@R)**：r≥R → r+n；**remove-row(R..E)**：R≤r≤E → 丢弃条目；r>E → r−(E−R+1)；**insert-col / remove-col / remove-cols（undo 复数形态，ADR-001 v1.5 规则 1 明录）** 同构换轴；**move-range(from→to)**：格 ∈ from → 平移 (to.from−from.from)；**remove-rows（undo 复数形态）**：按 remove-row 族同公式归一处理；**排序**：无确定性逐格映射 → **不迁移，整批走值校验兜底**（**本卡新定**：plan 规则 7 / ADR-001 v1.5 规则 1 将排序列入同步迁移集，本卡从严裁决不迁移，升级路径见待办 1） | plan 规则 7 + ADR-001 v1.5 规则 1 + **本卡新定**（排序从严裁决 + remove-cols 收录 + 公式成文） |
| 陷阱用例（入卡防呆） | **「插入后不撤销即导出」**：插后立即 undo 会「碰巧对齐」掩盖错位——必须断言迁移器捕获了 remove-rows（复数）mutation 本身，禁止仅比对坐标数值 | DESIGN-LAYER 任务书条 5 + plan 结构操作族用例 2 |

## ② 时序 / 状态机

**档案条目生命周期**：`诞生`（导入冻结/差分降级/静态化，D1-03 出口写入）→ `迁移`（六类结构 op 触发键变换）→ `失效`（用户编辑命中格）→ `丢弃`（remove 行/列含格、或导出值校验不等）→ `还原`（导出合并，值校验通过才写 f）。条目**只增删不改坐标语义**（迁移 = 删旧键写新键，Y.Map 单事务）。

**迁移器挂载点与双通道顺序（宿主 = D1-01 抑制矩阵，此处只落档案侧）**

```
本地结构 op：mutation handler 先改 cellData → onCommandExecuted 回调迁档案
             （同一命令执行栈、Y.Doc 单事务 emit——M3 实证一 op 恰一帧）
undo/redo：undo 前 focusUnit（否则静默 false）；undo 触发 remove-rows / remove-cols 复数形态（两轴都必须收录）
           → 按同坐标变换归一反向迁移（M4 实证双形态都必须收录）
远端回放：结构 mutation 回放完成后立即应用同源档案迁移
           （{onlyLocal, fromCollab}——迁移器对回放不二次迁移，防三重应用，M4 实证）
物化：A6 整表重写（resources ← 权威 Y.Map），顺序天然无歧义
```

**导出还原前置值校验（兜底闸门）**：逐条目校验「目标格当前 v === 档案 v」→ 相等还原 f（type=formula, value=当前 v）；不等 → 丢弃 + 降级说明「N 条公式因结构变更无法定位原格已不导出」（archive-dropped 原因码归 D1-03 枚举）。**v=undefined 条目例外（B5 评审补，本卡新定）**：无缓存值公式格（D1-03 ② 分支 ③）的档案 v 为 undefined，永远通不过相等校验——该类条目**跳过值校验直接还原 f**（打开时交 Excel 重算，与 D1-03「导出时 Excel 重算兜底」同源）；除此例外外 v 必填。**数据安全优先于文本保真**；值碰撞（错位格恰同值）概率可忽略且后果只是「值相同公式」，不产生数据破坏。

**失败分支**：① 迁移器不认识的未知结构 op（未来新增）→ 档案不动 + 值校验兜底（这正是闸门存在的意义）；② 物化时 Y.Map 与 cellData 意外失配 → 以 Y.Map 为权威重写（A6 语义），失配事件进审计日志；③ doc-rebuild（导入互斥，D1-01 五步）→ 档案随 resources 一体重建，无独立迁移路径。
