## ② 时序 / 状态机

**乐观更新（提交点 / 回滚点，以服务端 ack 为界）**

```
用户动作（重命名/新建/删除）
  → 本地立即应用（UI 层乐观变更：列表项就地更新）→ 状态 = **pending**（已本地应用、在途，动作项标记 pending 供 UI 弱化/禁用重复提交）
  → 发请求
       ├─ 2xx ack → 状态 = **confirmed**（保留乐观结果，与响应合并：以响应为准覆盖本地；清 pending 标记）
       └─ 失败 → 状态 = **rolled-back**（回滚到动作前快照 + Toast（错误类，含 D1-05 档位文案）
                  + 不吞错（console + 上报埋点））
                  —— **rolled-back 不是终态（v1.3 补，P2-5）**：回滚后该请求仍在途，
                     若迟到 ack（网络竞态）到达，**必须按 ① 失败分支以 ack 重放更新**，
                     即 rolled-back 态需保留「可重放」开口（保留动作参数或请求句柄），
                     回滚不撤销服务端真实状态
```

**三态不变量（v1.3 补）**：`pending → confirmed` 与 `pending → rolled-back` 是唯二正常转移；`rolled-back → confirmed`（迟到 ack 重放）必须可达——卡内失败分支①描述了该语义但伪码原把它画成终态，实现者按终态写会丢掉迟到 ack（V-OP 竞态用例会 FAIL）。

- 乐观范围**仅限列表页 CRUD**（重命名/新建/软删）；**编辑器内单元格编辑不做 HTTP 乐观**——协同写路径的"乐观"由 Yjs 本地即时生效天然提供，服务端确认走 write-through 落库（ADR-001），再用「保存指示四态」表达同步性：已保存（flush 完成）→ 保存中（在途）→ 离线（WS 断，待同步）→ 失败（重试入口 + 导出本地副本）。四态**从 WS 连接态 + flush 队列派生**，不经 HTTP。
- 回滚快照在动作发起时捕获（浅拷贝该列表项），失败回滚是同步操作——不存在中间态可观察窗口。

**任务类状态推进：轮询（不用 WS 推送）**

依据：契约已定 `GET /api/v1/import/{taskId}` 轮询间隔 ≥1s（openapi 端点 summary 明文）；导入是低频重操作，WS 推送需新增帧类型（frame-protocol 六类之外私扩 = 破契约）。退避：1s 起步，连续 4 次后 2s/4s/8s 封顶 8s；任务终态（success/failed）即停。页面隐藏（`visibilitychange` hidden）暂停轮询，恢复可见立即一次。

**只读降级单一事实源时序**

```
任一信号到达（HTTP 402 响应拦截 / WS close 4409 / 文件权限 403）
  → 前置护栏（v1.1 补，复评轮挑刺）：WS close 4409 且该连接已收 [CONTROL] doc-rebuild 帧
     （导入互斥窗口语义）→ **不进 readonly store**，走保存四态「离线待同步」缓冲 + 重建后重放
     （D1-05 v1.1 4409 分流规则 / D1-01 ② 失败分支 ③——4409 一码三语义，前端不得一律降级）
  → useReadonlyStore.setReadonly(source)
  → 派生：banner 渲染（三态文案按 license status 细分）+ 工具栏 Disabled + 公式栏 readOnly + 点击不进编辑态 + 首次点击 Toast「当前为只读模式」
  → 恢复条件：仅 license 状态轮询/重连成功且 source 对应的信号消失（防 402 未恢复而 4409 已恢复的误解除）
```

**失败分支与回滚点**：① 乐观回滚后如响应实际迟到成功（网络竞态）——以到达的 ack 重放更新（回滚不撤销真实状态）；② 轮询任务失败（网络错）≠ 任务失败——网络错重试 3 次后转「离线待同步」提示，不清任务态；③ doc-rebuild（P3-090）到达时**不乐观**：断开重建走标准加载协议，编辑器进 Loading 态（pages.md §3.11），此路径禁止乐观（重建期间乐观写会丢）。
