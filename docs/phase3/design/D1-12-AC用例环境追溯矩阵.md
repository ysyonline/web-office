**依赖列取值域声明（v1.3 补，P2-7）**：本列允许值 = **卡号引用**（`D1-xx`，可多个，可加括注）或 **`—`**（确无任何卡依赖）；**禁止**写「无关」「N/A」「待定」等值域外字符串——「无关」是语义双关（可指「无 License 依赖」也可指「无任何卡依赖」），AC-05 行即因此歧义填错，v1.3 已订正。

**冲突裁决**：AC-05 唯一数据出处 = Spec §9 档位明细（L0 5k/200ms、L1 10k/500ms、L1b 行为、L2 10s、L2b 行为）——**promise-tiering 档 1/2 的 300/800ms 是对外商务口径**（PM 更保守），验收断言**用工程口径 200/500ms**，两表不得混用（promise-tiering §7 映射表已列差异）；发现阈值失配走 Spec §9 变更流程，禁止验收脚本里私改阈值。**消歧义一句（v1.3 补，Q12）**：**「对内验收门槛 200/500 严于对外承诺 300/800」属有意设计、非矛盾**——promise-tiering §7「取更保守者」约束的是**对外承诺数字**（商务更保守 = 300/800 合规），对内用更严的工程口径 200/500 恰好给对外承诺留出余量（实测锚：中位 89ms/258ms）；二者方向一致，不得据「两表数字不同」判任一方错误。

**失败分支**：① E4-arm 环境不可得（金仓/鲲鹏资源排队）→ 该项标 blocked + 时间戳，**不冒充通过**；② LibreOffice 复核缺位 → AC-08 降为替代证据 + OPEN 登记；③ 自动化覆盖后发现 EARS 歧义 → 开 OPEN 交 Spec §9 澄清，脚本冻结待裁决。
