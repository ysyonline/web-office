## 一、竞品 UI 对比分析（4 家）

**Google Sheets**：单行工具栏（约 40px）+ 下拉菜单收纳低频功能，信息密度控制最佳；公式栏为「名称框 + fx 图标 + 编辑区」三段式；Sheet 标签底部条状排布；协同用彩色光标 + 名字标签 + 彩色选区边框，是协同可视化标杆。浅灰网格线（#E1E3E1）、表头浅灰底，整个网格区克制不抢戏。

**Excel Online**：Ribbon 多 Tab 分组，功能密度最高但对新手有压迫感；工具栏挤占视口问题被多篇工效学文章点名（有效工作区占比 EWR<0.75 时效率指数衰减）——教训：工具栏总高（标题栏+工具栏+公式栏）须控制在 120px 内。

**腾讯文档表格**：国内用户最熟悉的参照系。单行工具栏 + 更多功能收进「…」，蓝色主题；Sheet 标签在底部，右键菜单完整；协同头像堆叠在右上角，彩色选区 + 悬浮名字。

**飞书表格**：IM 融合最深，工具栏与 Sheets 同构但视觉更现代（更细的分割线、更轻的 hover 态）。

**结论**：MVP 取 Sheets 的工具栏结构（单行 + overflow 收纳）+ 腾讯文档的国内用户习惯（右键菜单、微信分享心智）+ Linear 级的克制视觉（「calm density」趋势：信息占 80%、装饰趋零、单一强调色、靠字号字重层级而非卡片盒子分组）。

## 二、对标品牌 + 设计语言

对标：**Google Sheets（结构范本）+ Linear（视觉范本）+ 腾讯文档（本土习惯）**。设计寄存器为 Product 型——设计服务数据，克制策略，无装饰性动效。三轴刻度：Variance 3 / Motion 3 / **Density 7（驾驶舱模式：紧凑 padding、1px 线分隔、禁止通用卡片容器包裹网格区）**。

## 三、配色基调 / 字体 / 风格关键词

- **主色：Emerald Green #059669**（电子表格品类心智色——Excel/Sheets/WPS 全是绿，与腾讯文档蓝、飞书蓝形成差异化）。强调色每屏 ≤2 处：仅用于选中 Sheet 标签、分享按钮、选中单元格描边。
- 中性色：暖灰阶（bg #F9FAFB / surface #FFF / border #E5E7EB / fg #111827），网格线 #E2E8F0、表头底 #F1F5F9，禁止纯黑纯白直出。
- 语义色：success #16A34A / warn #D97706 / danger #DC2626；协同光标调色板用 8 色高可辨识度系列。
- 字体：**Inter + Noto Sans SC**（UI），**JetBrains Mono** 用于公式栏与单元格数据（等宽是数字对齐刚需，也是专业感来源）。
- 风格关键词：冷静、精准、密集、可靠。无紫粉渐变、无渐变文字、无彩色左边框。

## 四、图标库（锁定一套）

**锁定 Lucide**：24×24 网格 + 2px stroke，ISC/MIT 协议，tree-shaking 极佳（45 图标约 12KB gzip），React 官方包齐全，覆盖表格全语义需求（bold/italic/underline、align 系列、table-cells-merge / table-cells-split、sigma、chart-bar、paint-bucket 等）。缺口图标以同库近似图标 + 同网格同描边自绘 SVG 补齐。尺寸规范：16px（行内）/ 20px（按钮内）/ 24px（独立），全项目统一。

## 五、表格编辑器关键 UI 区域清单及设计要点

1. **标题栏（~44px）**：文件名（可点击重命名）+ 云端保存状态（绿点/同步中 spinner）+ 协作者头像堆叠 + 分享按钮（主色，全页唯一常驻 CTA）。
2. **工具栏（~40px，单行）**：撤销/重做 | 字体字号 | B/I/U/文字色/填充色 | 对齐组 | 数字格式 | 合并单元格 | 冻结 | 函数 fx | 插入图表。分组间 1px 竖分隔线；hover 态 #F3F4F6 底 150ms；超宽收纳「…」溢出菜单；低频操作全部走右键菜单。
3. **公式栏（~32px）**：名称框（等宽字体，显示 A1）+ fx 按钮 + 编辑区（等宽字体、公式高亮着色）；进入编辑态 focus ring；引用单元格彩色描边联动。
4. **行列头（24px 行高/64px 列宽）**：默认 #F1F5F9 底 + #64748B 文字（12px）；hover 高亮该行/列；选中态 #E2E8F0 底 + 主色文字；拖拽调宽 1px 主色参考线 + 浮动尺寸 tooltip。
5. **网格区**：网格线 #E2E8F0（选中区域描边 2px 主色 + 右下角填充柄）；协同光标 = 协作者色 2px 边框 + 名字标签（超 4 人只显示光标）；多协作者选区各自颜色 10% 透明填充。
6. **Sheet 标签栏（~36px，底部）**：默认透明底，激活态 #E2E8F0 底 + 主色下划线 2px + 主色文字；「+」新建按钮恒在末尾；右键菜单（重命名/删除/复制/颜色）；支持拖拽排序。
7. **状态栏（~28px，可选）**：左：Sheet 数量与缩放控件；右：选中区域快速统计（求和/平均/计数，等宽字体）。

所有颜色走 Design Token（A1/A2/B-slot/C 四层），Phase 2 将产出 DESIGN.md + design-tokens.json + 各页面提示词。
